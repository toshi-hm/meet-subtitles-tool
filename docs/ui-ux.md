# UI/UX仕様

## 1. 基本方針

- 会議中に視界を大きく占有しない。
- 取得中かどうかを常に判別できる。
- 主要操作はワンクリックで完了する。
- 保存失敗時も字幕を失わないことを明確にする。
- `meet.google.com/home` と入室前の待機画面にはパネルを表示しない。

## 2. パネル状態

| 状態 | 表示 | 操作 |
| --- | --- | --- |
| 初期化中 | 「字幕機能を準備しています」 | なし／再試行 |
| 字幕待ち | 「字幕をONにしています」 | 手動ON案内 |
| 取得中 | 件数、最終取得時刻、コピー、TXT保存、Drive状態 | 折りたたみ、ドラッグ |
| 折りたたみ | 取得状態、件数、展開ボタン | 展開、ドラッグ |
| 同期中 | 「Google Driveへ保存中」 | 操作継続可能 |
| 同期済み | 「Driveに保存しました」 | Drive保存状態確認 |
| 同期失敗 | 「端末に保存済み。Drive保存を再試行できます」 | 再試行 |
| 入室後・未接続 | `Drive接続` | OAuthを開始し、会議中にDrive認証を完了 |

## 3. 操作仕様

### コピー

- ボタンラベル: `コピー`
- 成功通知: `字幕をクリップボードにコピーしました`
- 空データ: `コピーする字幕がまだありません`

### TXT保存

- ボタンラベル: `TXT保存`
- 成功通知: `TXTファイルを保存しました`
- 空データ: `保存する字幕がまだありません`

### Drive

- 入室後・字幕0件: `Drive接続`
- 認証中: `Google Driveに接続しています`
- 保存中: `Driveへ保存中`
- 成功: `Google Driveに保存しました`
- 失敗: `Drive保存に失敗しました。字幕は端末に残っています`

`Drive接続` は字幕本文を送信せず、OAuthだけを実行する。認証が完了するとボタンを `Drive保存` に切り替える。

## 4. ドラッグと折りたたみ

- ドラッグハンドルはパネルヘッダー全体とする。
- `aria-label="字幕パネルを移動"` を付ける。
- 画面外へ完全に移動できないよう、少なくともヘッダーが画面内に残る範囲で座標を制限する。
- 折りたたみボタンには `aria-expanded` を設定する。
- パネル位置と折りたたみ状態はMeetごとではなくブラウザプロファイル単位で保持する。
- パネルの右下リサイズハンドルをドラッグすると、幅・高さを変更できる。

## 5. レスポンシブ

- デスクトップ幅を主対象とし、最小幅320pxで内容が切れない。
- Meetの表示領域が狭い場合はパネル幅を縮小する。
- ボタンはマウスとキーボードの両方で操作可能にする。
- 固定幅で字幕本文を切り捨てず、本文は折り返す。
- ボタンの通常色は `#000048`、ホバー時は `#24246d`、押下時は `#5f5fa3` とする。

## 6. アクセシビリティ

- ボタン名だけで操作目的を理解できる。
- 色だけで状態を表現しない。状態文言とアイコンを併用する。
- フォーカスリングを削除しない。
- Escapeで通知を閉じられるようにする。
- `role="status"` の通知領域を用意し、成功・失敗を読み上げ可能にする。

## 7. プライバシー表示

初回Drive保存前に、次の説明を表示する。

> Google Drive保存を有効にすると、この拡張機能が作成する字幕TXTファイルをGoogle Driveの「Meet Subtitles」フォルダに保存できます。字幕はDrive保存以外の目的で外部送信しません。
